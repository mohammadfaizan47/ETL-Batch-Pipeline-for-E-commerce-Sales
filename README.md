# ETL-Batch-Pipeline-for-E-commerce-Sales
Summary: Efficient ETL pipeline made on Medallion Architecture works for Batch time series which takes Input data as definite amount and does Transformations.

Objective : Solving Load balancing, ACID transformation on Delta Tables, Visually better Dashboard, giving business solutions.

Tech Stack :\
Ingestion source: Kaggle dataset, \
Database: Unity Catalog, \
Transformstions: Databricks Notebooks(Pyspark), \
DataType: Delta Tables, \
Dashboard: Databricks Dashboard. \
